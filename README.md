# BMI Calculator 

A simple BMI (Body Mass Index) Calculator built with Python and Tkinter.

The application allows users to enter their weight and height, calculate their BMI, and see their BMI category.

# Features

- Enter weight in kilograms
- Enter height in centimeters
- Calculate BMI
- Display BMI value
- Show BMI category
- Handles empty inputs
- Handles invalid inputs
- Simple graphical user interface with Tkinter

# BMI Categories

- Severely Thin
- Moderately Thin
- Mildly Thin
- Normal
- Overweight
- Obese Class I
- Obese Class II
- Obese Class III

# Technologies Used

- Python
- Tkinter

# How to Run

1. Clone the repository:

    git clone YOUR_REPOSITORY_URL

2. Go to the project folder:

    cd BMI-CALCULATOR

3. Run the application:

    python3 main.py

# BMI Formula

BMI is calculated using:

    BMI = weight (kg) / height (m)²

Example:

    Weight: 60 kg
    Height: 167 cm

    BMI = 60 / (1.67 × 1.67)
    BMI ≈ 21.51

    Result: Normal
